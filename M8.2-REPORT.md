# JPPC M8.2 — BAT y traducción de direcciones

## Alcance

Esta iteración corrige la selección y aplicación de BAT en la MMU y conecta los SPR BAT y SR con el estado de la MMU.

## Cambios

- BATU/BATL de instrucciones (IBAT0–IBAT3) y datos (DBAT0–DBAT3) se consultan como ocho pares independientes.
- La búsqueda BAT compara la dirección efectiva contra BEPI y BL; ya no deriva el índice BAT del número de segmento.
- La dirección física se forma con BRPN y el desplazamiento dentro del bloque.
- La validez Vs/Vp se selecciona según MSR[PR].
- `mtspr`/`mfspr` para SPR 528–543 se conectan a los pares BAT de la MMU.
- `mtspr`/`mfspr` para SR0–SR15 (SPR 256–271) se conectan a los registros de segmento.
- Se añade `XenonMmuSelfTest` y su integración en `tests.sh`.

## Validación realizada

- `ant clean jar`: BUILD SUCCESSFUL.
- `./run.sh test`: exit code 0.
- 29 comprobaciones reportadas OK; 0 FALLA.
- Regresión LK, XeLL, Xenos, SATA/ATAPI y NAND sintética conservada.

## Limitaciones conocidas

Este milestone no pretende cerrar la MMU Xenon/PPC64 completa:

- La traducción BAT implementada aquí cubre el formato BAT clásico de 32 bits.
- Los permisos PP/WIMG y las variantes extendidas específicas de PPC64/Xenon aún requieren modelado y pruebas dedicadas.
- La traducción por TLB continúa siendo el modelo simplificado previo; SDR1/hash page table, tlbie/tlbsync y los fault registers DAR/DSISR no quedan completados por este cambio.
- El manejador general de DSI/ISI aún necesita una implementación completa de SRR0/SRR1 y semántica de retorno.
- La prueba de BAT comprueba traducciones supervisoras IBAT/DBAT y no demuestra todavía arranque de 1BL.

No se utilizó NAND real ni se incluyeron datos privados de consola.
