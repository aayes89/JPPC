# M8.4 — MMU Translation Fault Containment

## Alcance

Esta iteración se concentra en impedir que un fallo de traducción termine convertido en una dirección física sustituta (PA=0) y que la instrucción que originó el fallo continúe como si hubiera obtenido un resultado válido.

## Cambios

- `MMU.TranslationFault`: excepción tipada que conserva EA, tipo de acceso (instrucción/datos) y dirección de escritura/lectura.
- `MMU.translateAddress`: después de entregar DSI/ISI, aborta la traducción lanzando `TranslationFault`; ya no devuelve `0` en los casos de segmento Direct-Store no soportado ni de ausencia de BAT/TLB.
- `CPU.execute`: captura el fallo tipado sin transformarlo en Program Exception ni ejecutar un acceso físico posterior.
- `CPU.step`: captura fallos durante fetch de instrucción; aplica el vector preparado por la MMU y no decodifica una instrucción sustituta.
- `XenonMmuSelfTest`: verifica que una EA fuera del bloque BAT provoca fallo tipado y conserva la dirección efectiva.
- Configuración de ejecución: resolución predeterminada 1024x768; `run.sh xell` ejecuta `xenon.elf` a 1024x768.
- Regresión: eliminadas las ejecuciones de `fb_demo` y `triangle_fixed`; las pruebas de GPU/arranque se basan en Xenos y `xenon.elf`.

## Límite técnico

Este milestone no implementa aún TLB hardware completa, SDR1/hash page table, permisos PP/WIMG ni invalidaciones PPC completas. Tampoco demuestra arranque de 1BL. El enlace HTTP facilitado para `1bl.bin` no pudo resolverse desde el entorno de trabajo (fallo DNS de `cumxtv.ddns.net`); por tanto, esta iteración se validó con el `xenon.elf` incluido en el proyecto. No se descargó ni incorporó NAND real.
