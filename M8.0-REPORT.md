# JPPC — M8.0: Xenon Core Compatibility Foundation

## Alcance de esta entrega

M8.0 inicia la fase de consolidación del núcleo antes de ampliar la cadena de arranque. No declara compatibilidad completa de Xenon ni ejecución de 1BL. Se preservan las implementaciones de M7.8 y se agrega una regresión aislada para verificar contratos básicos del bus que afectan directamente a CPU, firmware y periféricos.

## Cambios

- `BusMappingSelfTest`: valida que el alias real-mode `0x80000000 + X` acceda a la misma RAM física que `X`.
- Valida lecturas/escrituras byte y word en un dispositivo MMIO registrado en `0xEA001300–0xEA0013FF`.
- Valida el orden big-endian de las transferencias de 32 bits del bus.
- La prueba se integra en `tests.sh`; no requiere NAND ni claves.
- Se mantienen las pruebas previas de CPU, LK, Xenos, SATA/ATAPI y SFCX.

## Orden de trabajo conservado

1. Consolidar CPU Xenon/PPC y estado arquitectónico.
2. Validar MMU, traducción y excepciones con pruebas específicas.
3. Consolidar el bus y los dispositivos MMIO.
4. Avanzar la cadena 1BL/CB y NAND, en modo de lectura y sin incluir material privado en entregables.
5. Validar SFCX/KeyVault únicamente con datos locales del propietario; nunca exportar secretos a reportes.
6. Avanzar firmware/dashboard después de demostrar los pasos anteriores.
7. Añadir carga de imágenes ISO y sistemas PPC como objetivo posterior, no como parte de M8.0.

## Límites conocidos

- La MMU actual mantiene BAT, SR y una TLB simplificada; no se declara equivalente a la MMU Xenon real.
- La suite de CPU existente no demuestra cobertura completa de PPC64, VMX128, SPR específicos de Xenon, excepciones ni coherencia de caché.
- La prueba nueva cubre direccionamiento y endianness del bus, no latencias, DMA, interrupciones ni semántica completa de cada periférico.
- El progreso de XeLL en M7.8 sigue limitado por la integración SATA/ATAPI descrita en `M7.8-REPORT.md`.

## Reproducción

```bash
./run.sh test
```

La prueba nueva también puede ejecutarse de forma aislada después de compilar:

```bash
java -cp out pcp.TESTS.BusMappingSelfTest
```

## Seguridad de datos

Este paquete no contiene `nand.bin`, dumps de NAND, CPU key, 1BL key, DVD key, KeyVault ni identificadores de consola. Las pruebas de M8.0 no requieren datos privados.
